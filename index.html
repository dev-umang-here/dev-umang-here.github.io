TRIAGE↓ / Alert-to-remediation loop / Agentic AI · SRE

Self-healing
on-call agent

Claude Agent SDK MCP Prometheus Kafka Kubernetes

An autonomous incident-response system for a microservice stack. Most on-call incidents repeat — a crash-looping worker, a bad deploy, a poison message, an OOM — and each has a known diagnosis path. The slow part is a human waking up and orienting.

Five agents run as a pipeline behind a deterministic Python state machine: detector, diagnostician, remediator, verifier, librarian. Telling failures apart needs reasoning — a stopped consumer and a crash-looping consumer look identical in the lag metric but need opposite fixes — so the agents own judgement while the orchestrator owns lifecycle and sequencing.

The safety layer is code, never the model: an allow-list, a confidence gate and a circuit breaker sit between any proposal and production, and the MCP tool surface separates read-only tools from destructive ones outright.
